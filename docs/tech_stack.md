# BharatNLP – Technology Stack

## 1. Overview

BharatNLP will use a combination of Artificial Intelligence, Machine Learning, Deep Learning, Natural Language Processing, Computer Vision and Full-Stack Web Development technologies.

The technology stack is selected to support modular development, multimodal model integration, real-time interaction and application deployment.

## 2. Programming Language

### Python
**Purpose:** Primary programming language.

Python will be used for:
- Data preprocessing and analysis.
- Machine Learning and Deep Learning.
- NLP and speech processing.
- Computer Vision.
- Multimodal fusion.
- Backend development.

## 3. Artificial Intelligence and Machine Learning

### PyTorch
**Purpose:** Deep Learning framework.

Used for:
- Neural network development.
- Model training and fine-tuning.
- Multimodal fusion architecture.
- Adaptive and attention-based fusion experiments.

### Scikit-learn
**Purpose:** Traditional Machine Learning and model evaluation.

Used for:
- TF-IDF feature extraction.
- Logistic Regression and SVM baselines.
- Data preprocessing.
- Classification metrics and model evaluation.

## 4. Natural Language Processing

### Hugging Face Transformers
**Purpose:** Accessing and fine-tuning pretrained transformer models.

### MuRIL
**Purpose:** Candidate multilingual model for Indian-language text processing.

### XLM-RoBERTa
**Purpose:** Candidate multilingual transformer for Hindi, English and code-mixed text experiments.

These models will be evaluated before selecting the most suitable model for the text module.

## 5. Audio Processing

### Librosa
**Purpose:** Audio processing and acoustic feature extraction.

Used for:
- Waveform analysis.
- Spectrogram generation.
- Pitch and energy extraction.
- Audio preprocessing.

### Whisper
**Purpose:** Speech-to-text transcription.

Used to convert speech input into text.

### Wav2Vec2 / SpeechBrain
**Purpose:** Candidate technologies for Speech Emotion Recognition experiments.

They will be evaluated for acoustic classification performance and compatibility with available datasets.

## 6. Computer Vision

### OpenCV
**Purpose:** Image and video processing.

Used for:
- Image loading and preprocessing.
- Face detection pipelines.
- Webcam frame processing.

### MediaPipe
**Purpose:** Facial landmark detection and face-related visual processing.
